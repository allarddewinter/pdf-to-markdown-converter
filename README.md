### OCR Approach (Inspired by Simon's Wisdom)
This tool follows the elegant approach pioneered by [Simon Willison's OCR tool](https://github.com/simonw/tools/blob/main/ocr.html):

1. **PDF Page Rendering**: Each PDF page is rendered to a high-resolution canvas
2. **Image Conversion**: Canvas content is converted to JPEG format for OCR processing  
3. **Tesseract OCR**: Advanced text recognition extracts content from the rendered images
4. **Structured Output**: Text is organized by pages with proper Markdown formatting
5. **Image Preservation**: Original page images are available for viewing and download

This approach ensures maximum text accuracy while maintaining visual context - truly what the Romans would have done if they'd had browsers.
