# 🔄 PDF to Markdown Converter

> Transform PDF documents into clean Markdown with advanced image extraction - all in your browser!

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Visit_App-blue?style=for-the-badge)](https://allarddewinter.github.io/pdf-to-markdown-converter)
[![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/allarddewinter/pdf-to-markdown-converter)

## ✨ Features

### 🎯 Core Functionality
- **🔒 Privacy First**: Zero server uploads - everything runs locally
- **📱 Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **🖼️ Image Extraction**: Advanced hybrid approach with intelligent fallbacks
- **⚡ Real-time Processing**: Live preview with progress tracking
- **🎨 Smart Formatting**: AI-powered heading detection and structure preservation

### 🛠️ Advanced Capabilities
- **📊 Table Detection**: Converts PDF tables to Markdown format
- **🎯 Multiple Export Formats**: Download as .md, .zip with images, or copy to clipboard
- **🌙 Dark/Light Theme**: Automatic theme switching based on system preference
- **🔍 Content Analysis**: Font-based hierarchy detection and list recognition
- **⚠️ Robust Error Handling**: Graceful degradation with visual feedback

### 🖼️ Image Processing
- **Hybrid Extraction**: Combines direct image access with canvas rendering
- **Smart Fallbacks**: Automatic text-only mode when images fail
- **Multiple Formats**: Supports PNG, JPEG, and embedded image formats
- **Optimized Output**: Compressed images with quality preservation

## 🚀 Quick Start

### Online Usage
1. Visit [allarddewinter.github.io/pdf-to-markdown-converter](https://allarddewinter.github.io/pdf-to-markdown-converter)
2. Drop your PDF file or click to browse
3. Watch the magic happen with real-time conversion
4. Download your Markdown file or ZIP with images

### Local Development
```bash
git clone https://github.com/allarddewinter/pdf-to-markdown-converter.git
cd pdf-to-markdown-converter
# Open index.html in your browser - that's it!
```

## 🎯 What Makes This Special

- **Single File Architecture**: Everything in one HTML file for maximum portability
- **Zero Dependencies**: Runs anywhere with just a modern browser
- **Progressive Enhancement**: Works on older browsers with graceful degradation
- **Accessibility First**: Full keyboard navigation and screen reader support
- **Performance Optimized**: Efficient processing with worker threads

## 🔧 Technical Stack

- **PDF Processing**: PDF.js with custom image extraction
- **UI Framework**: Vanilla JavaScript with modern ES6+ features
- **Styling**: Custom CSS3 with CSS Grid, Flexbox, and animations
- **Image Handling**: Canvas API with intelligent compression
- **File Management**: Blob API with ZIP generation
